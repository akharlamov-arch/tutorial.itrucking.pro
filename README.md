# tutorial.itrucking.pro

База знаний для клиентов iTrucking: пошаговые инструкции по порталу iTrucking Pro, топливным картам EFS и программе скидок на шины.

**Стек:** Vite · React 19 · TypeScript · React Router · CSS Modules · Vitest

## Запуск

```bash
npm install      # один раз
npm run dev      # локальный сервер с автообновлением
```

| Команда           | Что делает                                                     |
| ----------------- | -------------------------------------------------------------- |
| `npm run dev`     | Локальная разработка                                           |
| `npm test`        | Тесты, включая проверку всех туториалов                        |
| `npm run lint`    | Проверка кода                                                  |
| `npm run build`   | Сборка в `dist/` (с отдельной страницей для каждого туториала) |
| `npm run preview` | Посмотреть собранную версию локально                           |
| `npm run deploy`  | Выкладка `dist/` в S3 (см. ниже)                               |

## Как добавить туториал

1. Скопируйте папку `src/content/tutorials/_template` и назовите её адресом туториала латиницей через дефис,
   например `fuel-limits`. Туториал откроется по адресу `/tutorials/fuel-limits`.
2. Положите картинки в эту же папку (`cover-ru.png`, `cover-en.png`, `step-1.png`…) и подключите их через `import` в начале `index.ts`.
3. Заполните `index.ts`: категорию, порядок, название и описание на двух языках, затем блоки `body`.
4. Запустите `npm run dev` и проверьте туториал в браузере.
5. Запустите `npm test` — тесты сообщат, если забыт перевод, указана несуществующая категория или ссылка на другой туториал.

Регистрировать туториал где-то ещё не нужно — все папки подхватываются автоматически.

### Блоки

| Блок                                         | Что это                                                          |
| -------------------------------------------- | ---------------------------------------------------------------- |
| `{ type: 'text', text }`                     | Абзац текста                                                     |
| `{ type: 'image', src }`                     | Картинка (увеличивается по клику). `src` — одна или `{ ru, en }` |
| `{ type: 'list', title?, items }`            | Нумерованный список                                              |
| `{ type: 'steps', title?, variant?, items }` | Шаги. У каждого шага `title` и свои `blocks`                     |
| `{ type: 'callout', variant, text, image? }` | Выделенный блок, варианты ниже                                   |
| `{ type: 'appDownload' }`                    | Кнопки App Store / Google Play                                   |

Варианты `callout`: `solution` («Как это избежать»), `tip` («Совет»), `note` («Примечание»), `hint` (жёлтая подсказка 💡),
`warning` (оранжевая плашка), `info` (серая плашка), `conclusion` («Заключение»).

`steps` с `variant: 'secondary'` — дополнительный раздел (например, «Редактирование пользователей»); в счётчик шагов на карточке он не входит.

### Оформление текста

```
**жирный текст**
[ссылка на сайт](https://itrucking.pro/)
[ссылка на другой туториал](tutorial:ifta-report)
```

Перенос строки в тексте (`\n`) становится переносом строки на странице.

### Что считается автоматически

- **Количество шагов** на карточке — по блокам `steps`.
- **Время чтения** — по количеству слов (можно задать вручную полем `readTime`).
- **Рекомендуемые материалы** — следующие туториалы той же категории. Задать вручную: `related: ['slug-1', 'slug-2']`.
  Чтобы туториал не предлагался в рекомендациях к другим: `hideFromRecommendations: true`.

## Где что лежит

```
src/
  content/
    tutorials/<slug>/   туториал: index.ts + его картинки
    categories.ts       категории (кнопки фильтра)
    schema.ts           описание формата туториала
  config/site.ts        контакты, ссылки на соцсети и магазины приложений
  i18n/messages.ts      тексты интерфейса на RU и EN
  components/           компоненты интерфейса (у каждого свой .module.css)
  styles/tokens.css     цвета светлой и тёмной темы
scripts/
  prerender.ts          после сборки создаёт dist/tutorials/<slug>/index.html с превью для мессенджеров
  deploy.sh             выкладка в S3
```

## Деплой

Сайт размещён в S3 за CloudFront. Нужен настроенный AWS CLI (`aws configure`).

```bash
npm run build
DRY_RUN=1 S3_BUCKET=<бакет> npm run deploy                                  # посмотреть, что будет загружено
S3_BUCKET=<бакет> CLOUDFRONT_DISTRIBUTION_ID=<id> npm run deploy             # выложить и сбросить кэш
```

Страницы туториалов загружаются в S3 под ключами без расширения (`tutorials/ifta-report`) — так прямые ссылки
работают без дополнительной настройки CloudFront.
